# Helenfest Backend

Este backend de Node está preparado para crecer con la API de la web de la fiesta.

## Scripts

- `npm install`
- `npm run dev` para arrancarlo con recarga automática
- `npm start` para arrancarlo en modo normal

## Endpoints actuales

- `GET /` → mensaje base del backend
- `GET /api/health` → comprobación del estado del servidor
